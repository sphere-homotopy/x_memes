# x_memes

Small interactive web experiments from **sphere-homotopy**.

The repository is intentionally lightweight: mostly static HTML/CSS/JavaScript projects that can be opened directly in the browser and shared as standalone links.

## Projects

### Where Are You a Millionaire?

Enter an amount of money and see which countries make you a “millionaire” in local currency.

It uses live reference FX rates, highlights the closest million-unit threshold you already cross, and shows the next country to unlock.

**Live:** https://sphere-homotopy.github.io/x_memes/millionaire/

---

### Two Mirrors

An interactive geometric-optics model of two plane mirrors forming an angle.

Move the observer, change the angle, inspect virtual images, and see which reflection sequences correspond to a physically realizable light ray.

**Live:** https://sphere-homotopy.github.io/x_memes/

---

### CustomBoob

An interactive graph of

[
x(y)=a y\ln(y)-\frac{b}{36}\exp\left[-\left(36y-\frac{c}{e}\right)^m\right].
]

Adjust the parameters, zoom the plot, and inspect the negative branch.

**Live:** https://sphere-homotopy.github.io/x_memes/custom-boob/

## Technical style

- static GitHub Pages
- no framework unless the experiment actually needs one
- browser-first interaction
- small testable calculation modules
- shareable URLs where useful
